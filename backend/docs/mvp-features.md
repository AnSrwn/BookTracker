# BookTracker – MVP Features

> Status: Draft · Last updated: 2026-09-19

**Goal:** Users can add their books in the app (by scanning or manually), organize them on their own shelves and track their reading progress.

## Features

### User Accounts
- Sign up, sign in and sign out
- Delete the account including all personal data

### Save Books
- View and search the personal library as a list
- View and edit book details
- Remove books from the library

### Scan Books
- Scan the ISBN barcode with the camera
- Title, author, cover etc. are filled in automatically and can be corrected before saving
- The cover image is taken from the external book service (linked, not uploaded)

### Add Books Manually
- Add a book via a form if it has no barcode or the scan finds nothing

### Reading Progress
- Set a status: want to read / currently reading / read
- Enter the current page and see the progress

### Bookshelves
- Each user has multiple shelves, e.g. "My Books" and "Borrowed"
- Create, rename and delete custom shelves
- Put books on shelves and take them off again

## Out of Scope for the MVP
- Social features (friends, sharing, recommendations)
- Reading statistics and reading goals
- Ratings, notes, quotes
- Import/export (e.g. from Goodreads)
- Uploading own images (custom cover photos, profile pictures)
